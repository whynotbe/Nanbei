The user runs three AI coding agents — Claude Code, OpenAI Codex, and ZCode — and wants to hand off work between them. Since the tools' session formats are incompatible (ZCode can only resume its own `#sess_*` sessions via ReadSessionContext), the agreed convention (as of 2026-09-30) is file-based handoff in the project root:

- `AGENTS.md` — long-lived project context (stack, structure, commands, conventions). Codex and ZCode auto-read it; for older Claude Code versions, `CLAUDE.md` should reference AGENTS.md.
- `HANDOFF.md` — per-session snapshot the currently-working agent writes before ending: task goal, status, completed changes (file:line), next steps, key decisions, how to verify, pitfalls.

**How to apply:** When the user asks to hand off to/from Claude Code or Codex, write or read these files. When handing off from ZCode, generate the HANDOFF.md summary on request.
