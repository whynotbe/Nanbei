Discovered 2026-10-01: ZCode ships a full CLI at **`D:\Program Files\ZCode\resources\glm\zcode.cjs`** (v0.16.9, run with system node v24; wrapper script at `D:\Mir3-RL\工具-本机环境\zcode.cmd`). Not on PATH — `which zcode` finds nothing.

Key flags (verified via `--help` + tests): `-p/--prompt <text>` (headless single-shot, like `codex exec`; default permission mode yolo), `--resume <sess_...>` / `-c` (inject prompt into existing session), `--cwd <path>` (auto-reads that dir's AGENTS.md), `--mode build|edit|plan|yolo`, `--attach`, `--json`, `app-server` (ZCode Protocol over stdio; no MCP server mode, no HTTP API, no file-watch scheduler — built-in CronCreate is time-only). No top-level `--model` flag (printing help if passed).

Model selection for headless runs comes from **`~/.zcode/v2/provider_config.json`** → `config.defaultModelSelection` (`{providerId, modelId, options:{reasoningLevel}}`) — written by the desktop app itself. `defaultModelSelection` in `~/.zcode/config.json` or `~/.zcode/cli/config.json` is NOT read (harmless leftover fields exist there).

Gotcha: headless `-p` failed with "Model creation failed — Select a model before continuing" even with correct config, because the built-in provider was skipped by an **endpoint lease/cooldown** controller: `~/.zcode/v2/runtime/provider/windows-x86_64/<ver>/endpoint-*/zcode-builtin-refresh.json` (`nextEligibleAt` epoch-ms future timestamp → "ZCode Built-in skipped (not-due)" → empty provider registry). Also requires env `ZCODE_BUILTIN_PROVIDER_CONFIG_FILE=D:/Program Files/ZCode/resources/config/provider/zcode-builtin.json` (the CLI's own path resolution for this file is buggy — counts 5 levels up instead of 3). The `--resume` branch doesn't honor that env var ("ZCode Built-in missing") — unresolved as of session end; `-p` new-session mode suffices since cold-start reads AGENTS.md.

**How to apply:** When the supervisor (Claude Code) or user needs to push instructions to ZCode without the desktop app, use `zcode.cmd --cwd "D:\Mir3-RL" --mode edit -p "<instruction>"`. Retest after any lease cooldown expires. Answer doc for the supervisor lives at `D:\Mir3-RL\ZCode答-实时通道.md`. Related: [[multi-agent-handoff-workflow]].
