# 06 信息战系统(策划案)

## 概述

信息是乱世的第二货币。截获密信/伪造国书/散布童谣/审讯俘虏——玩家可以做侯景做过的一切,也可以阻止侯景做过的一切。信息战是关系网的"武器化"。

## 情报类型

| 类型 | 获取方式 | 价值 | 时效 |
|---|---|---|---|
| **军情** | 侦查/俘虏/截信 | 即时(敌军位置/兵力) | 短(1-3 天) |
| **政情** | 打听/朝堂/密探 | 中期(人事变动/政策) | 中(7-30 天) |
| **谶谣** | 民间/童谣/方士 | 长期(预言/预兆) | 长(永久,需解读) |
| **黑市** | 交易/威逼 | 即时(囤积/走私) | 短 |
| **内应** | 审讯/监控 | 极高(城内奸细) | 紧急 |

## 情报获取操作

### 侦查(Scout)

```
前提: 侦查技能 ≥ 1;到达目标区域附近
操作: 选择侦查范围(近/中/远) → 消耗时间(2/4/8 小时)
检定: 智谋 + 侦查技能 + 环境修正(夜晚+10%/雨+15%/城市+20%)
结果:
  成功: 获得情报(类型随机,按区域加权)
  失败: 无收获;被发现(敌警戒+)
  大成功: 额外获得一条隐藏情报
```

### 截获(Intercept)

```
前提: 知道信使路线(需先侦查);在路线上设伏
操作: 选择地点 → 等待(时间快进) → 判定
检定: 敏捷 + 潜行技能
结果:
  成功: 获得密信(可直接阅读/上交/篡改/伪造)
  失败: 信使逃脱;警戒+
```

### 打听(Inquire)

```
前提: 与目标区域 NPC polarity ≥ 1(或付金帛)
操作: 对话选择"打听" → 选择话题(军事/政治/人物/黑市)
限制: 每人每日 1 次;polarity 越高信息越多
```

### 审讯(Interrogate)

```
前提: 活捉敌将/间谍
操作: 选择策略(威胁/利诱/欺骗/酷刑)
检定: 智谋 + 口才 vs 目标忠诚度
结果:
  成功: 获得高价值情报
  失败: 目标自杀/提供假情报
  酷刑: 获得情报但声望-(严重)/暴戾度+
```

## 信息武器化

### 伪造文书(Forgery)

```
前提: 书法 ≥ 3 + 获得对方真迹(研究笔迹)
操作: 选择伪造类型:
  A. 伪国书(如侯景伪造东魏国书)
  B. 伪军令(调虎离山)
  C. 伪私信(离间)
检定: 书法 + 智谋 vs 接收方判断力
效果: 成功 → 接收方做出你期望的行为
      失败 → 被识破,关系网信任值-
```

### 童谣投放(Prophecy Planting)

```
前提: 谶谣解读 ≥ 2;有传播渠道(市井/军营/茶馆)
操作: 选择或创作童谣 → 选择投放区域
效果: 按内容不同:
  动摇敌方: 目标 NPC 忠诚度每日 -1
  鼓舞我方: 我方士气每日 +1
  预言自我实现: 为后续事件"铺垫舆论"
限制: 若被识破是伪造,声望-
```

### 离间(Sow Discord)——斛律光蓝本

```
四段式流程:
1. 投放渠道: 找到敌方内部有谗臣(信息战可查)
2. 内容设计: 拆字/谐音/暗示(如"百升飞上天,柏木霜可断")
3. 内部放大: 通过该谗臣传递给敌方主君
4. 目标行为: 敌方主君猜忌 → 处死/疏远目标武将

前提: 智谋 ≥ 6 + 谶谣解读 ≥ 3 + 敌方内部有内应
效果: 直接移除敌方一名武将(不战而屈人之兵)
限制: 每次消耗大量资源和时间;失败则反噬
```

### 告密(Informant)

```
操作: 将一方的秘密告诉另一方
效果: 
  - 被告密方: polarity 大幅下降(若发现是你)
  - 接收方: polarity 上升(暂时)
  - 全局: "信任值"下降(所有 NPC 初始 polarity -1)
设计意图: 告密有效但有长期代价——世界变得更冷
```

## 情报可信度

| 等级 | 显示 | 含义 |
|---|---|---|
| 高(绿色) | ✓✓✓ | 多方验证/亲眼所见 |
| 中(黄色) | ✓✓? | 单一来源/可能过时 |
| 低(红色) | ✓?? | 传闻/可能被误导 |
| 虚假(闪烁) | ✗✗✗ | 被识破的假情报 |

**设计意图**:情报不是"永远准确"的——玩家需要判断可信度,可能被反间。

## 与其他系统的接口

| 系统 | 接口 |
|---|---|
| 角色养成 | 智谋/侦查/书法技能决定操作效果 |
| 关系网 | 打听需要 polarity;告密影响信任值 |
| 围城经济 | 内应发现/黑市发现/援军联络 |
| 谶谣预言 | 童谣投放/解读 |
| 事件改写 | 节点②(截获回信)/⑥(发现内应)依赖信息战 |
