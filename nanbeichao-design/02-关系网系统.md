# 02 关系网系统(策划案)

## 概述

295 人的活网络,不是静态名单——每个人有 polarity(正负面)、忠诚度、性格标签,会因你的行为实时变动。**关系网是本游戏的"城市"**(其他游戏建造城市,我们经营关系)。

## 数据结构(已建,数据库直查)

```sql
-- persons 表(295 条)
id, name, courtesy, title_label, era, birth_year, death_year,
death_cause, home_region, faction, confidence, notes

-- relations 表(279 条)
subject_id → object_id, rel_type(13种), rel_detail,
start_year, end_year, weight, polarity(+1/-1/0),
confidence, evidence(原文引文), chunk_id

-- 视图:v_person_network(一跳关系网,SQL直查)
```

## polarity(正负面)规则

| 值 | 含义 | 效果 |
|---|---|---|
| +5 ~ +3 | 挚友/恩人 | 可托付性命/免费援助/婚姻 |
| +2 ~ +1 | 友好 | 优惠贸易/情报共享/推荐 |
| 0 | 中立 | 标准交互 |
| -1 ~ -2 | 不满 | 拒绝请求/散布负面 |
| -3 ~ -5 | 敌对 | 拒绝对话/主动攻击 |
| -5 以下 | 死敌 | 见面即战/派人暗杀 |

### polarity 变动事件表

| 行为 | 变动 | 备注 |
|---|---|---|
| 完成委托任务 | +1 ~ +2 | 任务难度越高加越多 |
| 送礼(对方喜好物品) | +1 | 每人每日限 1 次 |
| 战斗中救对方 | +3 | 高风险高回报 |
| 战斗中抛弃对方 | -3 | 不可逆(标记"背弃") |
| 杀害其亲属 | -5(永久) | 不可修复 |
| 谏言被采纳 | +2 | 需智谋检定 |
| 当众羞辱 | -2 | 魅力检定可减免 |
| 联姻(婚姻系统) | +3(双向) | 锁定盟友 |
| 荐举(为对方谋官) | +2 | 需声望 ≥ 对方门槛 |
| 告密(对方向) | -4 | 若对方发现则永久 |
| 免奴(侯景式动员) | +5 | 阶级感激(但可能被反向策反) |

## 网络操作(玩家可执行)

### 拉拢(核心操作)
```
前提: polarity ≥ -1,目标有所求(金/权/情/义)
流程: 选择策略(送礼/立功/联姻/免奴) → 检定(魅力+声望+策略匹配度)
成功: polarity +2,解锁该 NPC 的关系网(二跳可见)
失败: polarity -1,冷却 7 天
```

### 打听(情报操作)
```
前提: 与目标 NPC polarity ≥ 1,或付金帛
效果: 查看目标的一跳关系网(谁的盟友/谁的敌人)
限制: 每人每日限 1 次;polarity 越高看得越深
```

### 荐举(政治操作)
```
前提: 自己声望 ≥ 10,且与上位者(刺史以上) polarity ≥ 2
效果: 被荐举者获得官职/军职;polarity +2;自己在该上位者处声望 +1
限制: 每年限 2 次
```

### 联姻(高阶操作)
```
前提: 声望 ≥ 15,或对方主动提议
效果: 双方 polarity 锁定为 ≥ +3,不可轻易下降;解锁家族网
代价: 消耗大量聘礼(金帛/土地);可能同时得罪第三方
```

### 背叛(暗线操作)
```
前提: 与对方 polarity ≥ 1(必须先获得信任)
效果: 短期获得对方敌对阵营的接纳;全网"信任值"永久下降(所有 NPC 初始 polarity -1)
设计意图: 背叛有代价——不是不能背叛,是每次都让世界更冷
```

## 网络崩塌与重建(548 触发)

**事件触发**:台城陷落后,建康关系网被物理撕碎(士族覆灭)。

| 阶段 | 网络状态 | 玩家任务 |
|---|---|---|
| 548.10 围城前 | 建康网完整(约 50 活跃 NPC) | 经营/拉拢/情报 |
| 549.3 城破 | 70% NPC 死亡/流亡/失踪 | 确认幸存者(打听) |
| 549-551 | 网络碎片化(各地割据) | 重连(寻找流亡者) |
| 551-552 | 荆州系/岭南系两张新网 | 选边站或搭桥 |
| 552 光复后 | 网重建(但旧关系已变) | 新平衡 |

**技术实现**:数据库 persons 表按 `death_year > 当前年` 过滤,实时展示"活人网"。

## 界面设计

### 关系网可视化(D3.js 力导向图)

```
中心 = 玩家
一跳 = 直接关系 NPC(颜色 = polarity:绿正/灰中/红负)
二跳 = 拉拢后解锁的间接关系(半透明)
线 = 关系类型(粗细 = weight,颜色 = polarity)
点击 NPC → 弹出卡片(属性/关系/可执行操作)
```

```

│                                 │

```

## 与其他系统的接口

| 系统 | 接口 |
|---|---|
| 角色养成 | 魅力影响拉拢成功率;名师加速属性成长 |
| 战斗 | 关系网决定援军到达/polarity 决定是否背刺 |
| 冤气超度 | 超度亡者可改善其遗族 polarity |
| 围城经济 | 援军观望(节点⑤)需要关系网深度 |
| 信息战 | 打听 = 情报来源;告密 = 信息武器 |
| 宗室名册 | 宗室的威胁值受其关系网影响 |
| 事件改写 | 多数改写节点需要"关系网深度 ≥ 阈值" |
