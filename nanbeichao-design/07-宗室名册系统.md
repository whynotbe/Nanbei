# 07 宗室名册系统(策划案)

## 概述

南朝皇族的"保险精算表"——可视化家族树,实时显示谁活着/谁死了/谁将被杀。**"愿后身世世勿复生天王家"**是整个系统的设计起点。玩家可以预警/庇护/利用宗室成员的死亡。

## 数据来源

数据库 persons 表,筛选 `era LIKE '%梁%' OR era LIKE '%陈%'` + `faction LIKE '%宗室%' OR name LIKE '萧%'`,共约 40 人。

## 威胁值系统

每位宗室成员有"威胁值":

```
威胁值 = 继承权重 × 兵权权重 × 声望权重
继承权重: 太子=10/嫡子=8/庶子=5/宗室远支=2
兵权权重: 持节都督=3/有私兵=2/无兵=1
声望权重: 贤名远播=3/普通=2/恶名=1
```

### 威胁值触发

| 威胁值 | 皇帝/权臣反应 | 玩家预警 |
|---|---|---|
| > 20 | 启动清洗(下毒/暗杀/贬谪) | 可提前通知目标逃亡 |
| 15-20 | 密切监控/削兵权 | 可建言"自污"降低威胁 |
| 10-15 | 正常对待 | — |
| < 10 | 安全 | — |

## 玩家操作

### 预警(Warning)

```
前提: 威胁值 > 15 + 与目标 polarity ≥ 2 + 信息战获取清洗情报
操作: 告知目标"有人要杀你"
效果: 目标可能逃亡/自保 → 该人存活(家族树变化)
代价: 若被皇帝发现是你通风报信 → 你的威胁值上升
```

### 庇护(Shelter)

```
前提: 声望 ≥ 15 + 有安全地点(寺庙/边镇)
操作: 将目标藏匿
效果: 目标存活;后续可能成为你的政治资本
风险: 被发现 → 声望-/被追杀
```

### 自污建议(Strategy)

```
前提: 与目标 polarity ≥ 3 + 口才 ≥ 5
操作: 建议目标"自污"(贪财/纵乐/示弱)以降低威胁值
史实蓝本: 兰陵王"受财货"自污(尉相愿出的主意)
效果: 威胁值 -8;但可能不被采纳(性格判定)
```

### 利用(Exploit)

```
操作: 利用宗室死亡触发的事件
示例: 
  - 萧统死后继承危机 → 玩家可影响太子人选
  - 侯景立萧栋 → 玩家可选择保护或抛弃
  - 宗室内战 → 玩家可选边站
```

## 死亡预警(实时事件)

当系统检测到某宗室成员即将被杀(史实死亡日期临近),弹出:

```
┌─────────────────────────────────────┐
│  ⚠ 宗室预警                          │
│                                     │
│  萧誉(河东王)预计将于 3 个月内被杀     │
│  死因: 与萧绎内战,城破被杀             │
│                                     │
│  [通知萧誉逃亡] [庇护] [不管]         │
└─────────────────────────────────────┘
```

## "天王家"成就/结局

| 成就 | 条件 | 描述 |
|---|---|---|
| "天厌梁德" | 不干预任何宗室死亡 | 史实线:宗室几乎灭族 |
| "存亡续绝" | 存活 5+ 宗室成员 | 家族树改变;可能延续梁朝 |
| "愿后身世世" | 存活萧方智(末帝)到 557+ | "天王家"的诅咒被打破 |
| "改天换地" | 自己成为新的"宗室"(称帝线) | 极难条件 |

## 与其他系统的接口

| 系统 | 接口 |

| 信息战 | 清洗情报/死亡预警的获取 |
| 事件改写 | 节点⑨(王僧辩之死)涉及宗室选择 |
| 冤气超度 | 宗室成员的死亡产生大量怨气 |
