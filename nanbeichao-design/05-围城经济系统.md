# 05 围城经济系统(策划案)

## 概述

台城围城 130 天是本游戏最核心的体验段——**不是打怪,是活着**。粮价曲线/人口衰减/疫病蔓延/援军消息/内应发现,全部数值化、可视化、可干预。玩家的每一个决定(分粮给谁/派谁出城/要不要开城门)都改变结局。

## 核心循环

```
口粮(有限) → 分配(军/民/伤员) → 消耗(天数)
    ↓
补给获取(抢掠/外援/突围/黑市)
    ↓
士气/健康/疫病 → 守城能力
    ↓
结局: 坚守待援 / 突围 / 投降 / 饿死
```

## 时间系统

| 项目 | 规则 |
|---|---|
| 时间粒度 | 1 天(子时-亥时,快进可跳到次日) |
| 关键时点 | 每天的: 分配口粮(辰时)/守城战斗(午时)/夜间事件(子时) |
| 总时长 | 史实 130 天(548.10.13 - 549.3.12) |
| 加速 | 非关键日可"快进 N 天"(消耗资源,触发随机事件) |

## 口粮系统

### 基础数据(史实校准)

| 指标 | 初始值 | 日消耗 | 来源 |
|---|---|---|---|
| 城内军民 | 100,000 | — | 史实"十余万" |
| 军队 | 30,000 | 3 合/人/日 | "贯甲者三万" |
| 平民 | 70,000 | 2 合/人/日 | — |
| 存粮 | 400,000 石 | 66,000 合/日 | "公卿负米得四十万斛" |
| 可支撑天数 | ~60 天(理论) | — | 130 天实际(含减员/抢掠/外援) |

### 粮价曲线(核心可视化)

| 天数 | 粮价(每升) | 事件 | 玩家可干预 |
|---|---|---|---|
| 1-30 | 正常(30 钱) | 围城开始,秩序尚在 | — |
| 31-60 | ×10(300 钱) | 减膳;煮弩/烤马鞍;黑市出现 | 搜刮/黑市交易/分粮决策 |
| 61-90 | ×100(3,000 钱) | 人相食(侧写);疫病起 | 医术/找药/隔离决策 |
| 91-130 | 无价 | 死亡率 >50%;守埤者仅 2-3 千 | 终极抉择:突围/死守/投降 |

### 分粮决策(每日辰时)

```
界面: [存粮 XXX 石] [军队 XX 人] [平民 XX 人] [伤员 XX 人]
分配方案:
  A. 军队优先(战斗力保持,民怨+)
  B. 均分(各方满意,军队战力下降)
  C. 民优先(声望+,军队不满)
  D. 自留(主角囤粮,暴戾度+)

效果: 分配方案影响每日的:
  - 军队士气(→守城战力)
  - 平民暴动概率(→内乱事件)
  - 疫病传播速度(营养不良 → 免疫-)
```

### 粮食获取途径

| 途径 | 风险 | 收益 | 条件 |
|---|---|---|---|
| 抢掠城内富户 | 声望-(严重) | 中量 | 魅力低反而有效(不怕骂名) |
| 黑市交易 | 金帛 | 少量 | 有人在囤积(信息战可发现) |
| 外援输送 | 极高风险 | 大量 | 需关系网+信息战打通路线 |
| 水路偷运 | 高(敌军巡逻) | 中量 | 需潜行+水路地理知识 |
| 突围抢割 | 极高(战斗) | 一次性 | 需武力+兵力 |

## 人口系统

### 人口分类(动态追踪)

| 类别 | 初始 | 衰减因素 | 影响 |
|---|---|---|---|
| 军队 | 30,000 | 战死/饿死/逃亡 | 守城战力 |
| 壮丁 | 20,000 | 饿死/征召 | 劳力(修墙/运土) |
| 老弱 | 30,000 | 饿死/疫死(最快) | 消耗资源但无产出 |
| 妇孺 | 20,000 | 同上 | — |
| 伤员 | 0→动态 | 战斗产生 | 需额外口粮/医术 |

### 疫病系统

| 指标 | 规则 |
|---|---|
| 触发 | 第 60 天起,每日 5% 概率(营养不良+尸体堆积) |
| 传播 | 每日 2-5% 人口感染;高密度区更快 |
| 死亡率 | 感染者每日 3-8% 死亡(体质/营养/医术影响) |
| 干预 | 医术 ≥ 3 → 隔离区(减缓 50%);草药(治疗 10-20 人/日) |
| 史实对照 | "城中疾疫,死者太半" |

## 守城战(与战斗系统联动)

### 每日战斗流程

```
午时(12:00) → 侯景军攻城
    → 判断: 今日强度(弱/中/强,随机+剧情)
    → 玩家选择: 
       A. 参与一线(战斗,消耗 HP/精力)
       B. 指挥调度(需战术 ≥ 3,消耗精力,提升守军效率)
       C. 修墙/运土(消耗体力,提升城防)
       D. 休息(回复 HP/精力,明天再战)
    → 结果: 
       城防值变动(0-100,低于 20 可能被突破)
       伤亡(军队减少)
       事件(攻城器械/火攻/地道——触发特殊应对)
```

### 攻城器械对应(侯景的攻,玩家的守)

| 侯景用 | 玩家应对(需技能) | 史实出处 |
|---|---|---|
| 楼车(高十丈) | 等它自己倒(羊侃:"车高堑虚,彼来必倒") | 台城 |
| 土山 | 城内也起土山对峙(消耗壮丁) | 台城 |
| 地道 | 长堑截断+鼓风吹火 | 台城/玉壁 |
| 火攻 | 凿门楼+下水沃火 | 台城 |
| 虾蟆车 | 城上飞石(投石机) | 台城 |
| 水攻(决玄武湖) | —(无法应对,增加城内水患) | 台城 |

## 援军系统(与关系网联动)

### 援军到达条件

```
到达时间 = 初始延迟(30天) + 关系网深度修正
关系网深度 = Σ(各路都督的 polarity)
公式:
  到达天数 = 30 - min(关系网深度, 20)
  例: 关系网深度 15 → 第 15 天到达
```

### 援军行为(核心痛点)

| 状态 | 条件 | 效果 |
|---|---|---|
| **观望** | polarity < 阈值(默认 5) | 到达但"置酒高会" |
| **试探性进攻** | polarity 5-10 | 派小股部队,效果差 |
| **全力进攻** | polarity > 10 | 大军压境,可能解围 |
| **内讧** | 援军统帅之间 polarity < 0 | 互相牵制,不进攻 |

### 玩家干预(节点⑤)

```
方式 A: 冒险出城联络 → 说服柳仲礼(需 polarity ≥ 3 + 口才 ≥ 5)
方式 B: 直接夺兵权(高风险: 需武力 ≥ 10 + 战功)
方式 C: 暗杀(需暗器 ≥ 3;可能更糟——随机)
方式 D: 什么都不做(史实: 援军观望 130 天)
```

## 内应系统(节点⑥)

| 项目 | 规则 |
|---|---|
| 内应数量 | 史实 2 人(白昙朗/董勋华) + 随机 0-2 |
| 发现方式 | 信息战(截获密信)/夜巡(撞见)/审讯俘虏 |
| 应对 | 报告守军(处决,但可能还有别的内应)/设伏 |
| 未发现后果 | 城破提前(节点⑥触发) |

## 结局分支(围城段)

| 结局 | 条件 | 后续影响 |
|---|---|---|
| **坚守成功** | 存粮 ≥ 20 天 + 城防 ≥ 50 + 援军进攻 | 史实改写;梁朝延续 |
| **突围成功** | 选择突围 + 武力 ≥ 8 + 兵力 ≥ 5000 | 退往荆州;后续第三幕 |
| **城破(史实)** | 城防 = 0 或 内应未发现 | 第三幕照常触发 |
| **投降** | 士气 < 20 或 玩家选择 | 侯景阵营线(黑深残) |
