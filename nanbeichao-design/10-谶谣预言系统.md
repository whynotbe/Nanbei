# 10 谶谣预言系统(策划案)

## 概述

84 条志怪事件中,约 35 条是"预言类"(童谣/梦兆/拆字/天象/祥瑞)。它们不是"剧透"——是**需要解读的谜题**。灵识越高,解读越准确;但预言可能自我实现,也可能被反向操作。

## 谶谣解读机制

### 触发

```
方式 A: 玩家在特定地点听到 NPC 唱童谣 → 自动记录
方式 B: 灵识 ≥ 5,在志怪事件触发点感知 → 获得"预兆"
方式 C: 信息战操作"打听"→ 偶然获取
方式 D: 与特定 NPC(僧通/宝志传人)对话 → 获得解读
```

### 解读检定

```
灵识 + 谶谣解读技能 vs 预言难度
成功: 显示预言的"应验条件"(如:白马+青丝=侯景)
部分成功: 显示模糊提示(如:与"马"有关)
失败: 只记录原文,无解读
大失败: 错误解读(可能误导玩家做出错误决策)
```

## 预言自我实现

### 机制

当玩家"相信"一个预言后:

```
IF 玩家在预言相关区域做出选择
AND 该选择受预言影响(如: 因知道"青丝白马"而特别注意白马)
THEN 事件触发概率 +15%
```

### 反向操作

```
IF 玩家知道预言内容
AND 选择"反着来"(如: 明知采石会失守,偏去采石守)
THEN:
  改写节点解锁(节点③)
  但"气运"消耗 ×1.5(逆天而行)
```

## 预言与改写的交互

| 预言 | 对应改写节点 | 反向操作 |
|---|---|---|
| "青丝白马寿阳来" | ③采石渡江 | 在采石设防 |
| "百日天子" | —(不可改) | 侯景必败,只是时间问题 |
| "的脰乌" | ⑩反攻汇总 | 预知建康光复时机 |
| 双兔碑 | —(尔朱荣线) | — |
| 陈氏二百年预言 | ⑨陈霸先受禅 | 可阻止或加速 |
| 浮图入海 | —(北魏分裂) | — |

## 特殊 NPC(预言者)

| NPC | 能力 | 获取方式 |
|---|---|---|
| **僧通** | 狂僧,随机出现,每次预示一个关键事件 | 全地图随机encounter |
| **宝志(已死)** | 遗言/传人可解读 | 找到传人(支线) |
| **婆萧** | 岭南巫术,教主角基础解读 | 序章导师 |
| **范缜传人** | "神灭论"者,否定一切预言 | 随机encounter(反向) |
