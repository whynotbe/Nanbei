# 04 冤气超度系统(策划案)

## 概述

冤气是本世界的"暗物质"——大量非正常死亡者的怨气凝聚成的场,影响物理(鬼物显形)、心理(NPC 暴戾度)和系统(超度效力)。玩家的"阴阳眼"能看见它,超度能净化它,**净化一处浩劫=解锁一个改写节点**。

## 怨气法则(世界规则)

### 产生
- 每一个非正常死亡(战死/被杀/饿死/冤死)产生怨气单位
- 怨气不消散,在地理上积累 → **浩劫之地=怨气峰值**
- 数据来源:关系库 events 表中 event_type IN ('战争','灾异','政变') 且有人口死亡数据

### 分布(怨气地图,9 个峰值)

| 峰值 | 浓度 | 事件 | 年代 | 改写节点解锁 |
|---|---|---|---|---|
| 宁平城 | 70% | 十余万人覆没 | 311 | — |
| 参合陂 | 65% | 四五万降卒坑杀 | 395 | — |
| 统万城 | 50% | 人墙(筑尸入墙) | 413 | — |
| 河阴 | 75% | 两千朝官沉河 | 528 | — |
| 玉壁 | 60% | 七万人战死 | 546 | — |
| **台城** | **90%** | **十余万军民存者什一二** | **549** | **④⑤⑥** |
| **三吴** | **85%** | **千里绝烟白骨成聚** | **551** | **⑥** |
| **江陵** | **88%** | **焚书十万口北驱** | **554** | **⑧** |
| (全图其余) | 0-40% | 各地零星 | — | — |

### 影响(三层)

| 层 | 机制 | 数值 |
|---|---|---|
| 物理层 | 鬼物显形阈值降低 | 浓度 >80% 自动显形;>50% 夜间显形 |
| 心理层 | NPC 暴戾度上升 | 每进入高浓度区,该区 NPC 对话选项减少 30% |
| 系统层 | 超度系技能效力增强 | 浓度 ×0.5 = 超度威力加成% |

### 全局参数(可调)

```python
anima_threshold = 80  # 显形阈值(0-100)
# 100 = 纯历史(无鬼物)
# 0 = 全图鬼物横行(纯粹的刀剑封魔录)
# 默认 80 = 明面克制(常态妖魔不显形)
```

## 阴阳眼(主角的天赋)

### 感知层级

| 等级 | 灵识需求 | 能力 |
|---|---|---|
| Lv1(天生) | 7 | 看见怨气浓度(颜色叠加) |
| Lv2 | 9 | 看见怨魂(可交互/超度) |
| Lv3 | 11 | 看见怨气流向(预判鬼物出没) |
| Lv4 | 13 | 看见死者的"最后记忆"(线索) |
| Lv5 | 15 | 看见"命运线"(谶谣解读增强) |

### 视觉表达

```
浓度 0-20%: 无视觉变化
浓度 21-50%: 边缘出现灰色 vignette
浓度 51-80%: 红色 vignette + 微弱人影
浓度 81-100%: 深红 vignette + 空气扭曲 + 怨魂可见 + 耳语声
```

## 超度系统(净化)

### 超度方式(4 条路线)

| 方式 | 前置 | 效力 | 消耗 | 特殊 |
|---|---|---|---|---|
| **巫术超度** | 灵识 ≥ 8+婆萧教学 | 弱(单次-10%) | 灵识-5(临时) | 不需外物;岭南系 |
| **佛寺超度** | 灵识 ≥ 8+佛寺好感 ≥ 5 | 强(单次-30%) | 金帛(供奉) | 需到佛寺;正统系 |
| **安葬** | 体力 ≥ 5 | 中(单次-20%) | 时间+体力 | 最朴素;无 side-effect |
| **禁术·吸收** | 灵识 ≥ 12+特定NPC教学 | 极强(单次-50%) | 暴戾度+10 | 化怨为力;暗结局线 |

### 超度流程

```
1. 感知(灵识检定)→ 确认怨气源
2. 定位 → 找到遗骨/遗物/凶宅
3. 选择方式 → A/B/C/D
4. 执行 → 
   A 巫术: 交互仪式(30s)+灵识判定
   B 佛寺: 携遗骨至佛寺+僧人交互+金帛
   C 安葬: 携遗骨至安全地+挖掘+掩埋
   D 吸收: 直接交互(即时)
5. 完成 → 怨气浓度下降;可能获得善缘/记忆碎片/暴戾度
```

### 净化与改写绑定(核心设计)

```
规则: 净化一处怨气峰值 → 解锁该处的改写节点
示例:
  净化台城(90%→0%) → 解锁节点④(羊侃之死)、⑤(援军观望)、⑥(城破)
  净化三吴(85%→0%) → 解锁节点⑥(三吴浩劫的阻止)
  净化江陵(88%→0%) → 解锁节点⑧(焚书阻止)

设计意图: 超度不是"打怪刷经验",是"清扫历史的伤口"——
你净化了过去,才有资格改写未来。
```

## 范缜难题(超自然浓度的哲学阀门)

### 背景
范缜(450-510)"神灭论"——形存则神存,形谢则神灭。两次孤身对抗国家级围攻。

### 游戏实现
- 范缜本人已死于游戏时间线之前,但"神灭论"由匿名弟子传承
- 玩家在全地图随机遇到"神灭论者"NPC
- 每次 encounter → 一场小型辩论(选择"支持/反驳/沉默")

### 效果

| 选择次数 | 全局效果 |
|---|---|
| 支持 ≥ 5 | `anima_threshold` +5(鬼物更少) |
| 反驳 ≥ 5 | `anima_threshold` -5(鬼物更多) |
| 混合 | 保持默认 80 |

### 人间道结局

```
条件: 净化全部 9 个怨气峰值 + 支持范缜 ≥ 5
效果: 鬼物彻底绝迹 → 超度系统失效 → 改写节点锁死
结局画面: 纯人间线——玩家平凡终老
字幕: "没有鬼的世界,历史依然残酷——但那是人的残酷,不是天的。"
```
