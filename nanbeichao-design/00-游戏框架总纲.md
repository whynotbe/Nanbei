# 00 游戏框架总纲(策划案索引)

## 一句话定位

**"太阁立志传"的模拟骨架 + "刀剑封魔录"的战斗血肉,架在南北朝侯景之乱(547-557)上的开放世界 ARPG——你能看见怨气,你能改写历史。**

## 核心身份

| 维度 | 内容 |
|---|---|
| 类型 | 开放世界·模拟·动作 RPG |
| 时间 | 547 年正月 → 557 年(可延长至 589) |
| 空间 | 岭南→湘赣→三吴→建康(可扩展至北方) |
| 主角 | 岭南寒门武人,油库吏之子,天生"阴阳眼" |
| 核心机制 | 关系网经营 + 怨气感知与超度 + 历史改写节点 |
| 美术风格 | 写实中国风,岭南湿热→江南雅致→战场暗红 |
| 目标平台 | PC 优先(Steam),后续主机 |
| 引擎 | Godot 4(推荐,免费+轻量)或 Unity(视团队熟悉度) |
| 单周目时长 | 主线 25-35 小时,全收集 60+ 小时 |

## 核心循环(Core Loop)

```
探索世界 → 互动(关系网/情报/贸易)
    ↓
接受任务/触发事件(改写节点 or 支线)
    ↓
准备(养装备/招人/查谶谣/净化怨气)
    ↓
执行(战斗/对话/潜行/超度)
    ↓
后果(世界状态改变/关系网变动/怨气变化)
    ↓
新探索目标解锁 ← 回到顶部
```

**循环周期**:微观(单任务 10-30 分钟)→ 中观(章节 3-5 小时)→ 宏观(时代幕 10+ 小时)

## 游戏三幕结构

| 幕 | 时间 | 地理 | 教学内容 | 核心体验 |
|---|---|---|---|---|
| 序章 | 547.1-547.8 | 岭南 | 移动/对话/基础战斗/怨气感知/超度入门 | 世界观建立,"你是谁" |
| 第一幕 | 547.9-548.9 | 建康 | 关系网/情报/朝堂/信息战 | "这个世界怎么了" |
| 第二幕 | 548.10-549.3 | 台城围城 | 围城经济/守城战/资源管理/道德抉择 | "你能做什么" |
| 第三幕 | 551-557 | 三吴/江陵/岭南 | 反攻/大战略/结局分支 | "你做了什么" |

## 关键设计决策(已定,附推翻开关)

| 决策 | 方案 | 推翻开关 |
|---|---|---|
| 主角出身 | 岭南寒门武人 | 换序章+初始关系网,主线不动 |
| 起局年份 | 547 正月 | 改 548 则砍纳降教学段 |
| 超自然浓度 | 冤气体系化+明面克制 | 改 `anima_threshold` 一个参数 |
| 尺度 | 惨剧侧写+机制化 | 红线设计,不建议推翻 |
| 多结局 | 6 种(含人间道/入魔) | 增删结局只改判定条件 |
