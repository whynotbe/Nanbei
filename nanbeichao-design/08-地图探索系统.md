# 08 地图探索系统(策划案)

## 概述

三层地图:大地图(时代/疆域/交通)→ 城市图(可交互节点)→ 关卡图(战斗/探索/剧情)。玩家从岭南到建康的地理动线,是"从边缘走向中心"的叙事动线。

## 三层结构

### 第一层:大地图(战略地图)

| 项目 | 规格 |
|---|---|
| 尺寸 | 约 3000×2000(经纬投影) |
| 覆盖 | 岭南(南)到淮河(北),四川(西)到海(东) |
| 视角 | 俯视 45°,可缩放 |
| 交互 | 点击城市 → 进入城市图;选择路线 → 移动 |

#### 大地图标注

| 类型 | 图标 | 数量 | 说明 |
|---|---|---|---|
| 都城 | ★ | 3(邺/长安/建康) | 主场景入口 |
| 州治 | ● | 30+ | 次级场景 |
| 军镇 | ▪ | 8(玉壁/涡阳/采石等) | 战场关卡 |
| 佛寺 | 卍 | 10+ | 超度/存档 |
| 怨气峰值 | 红色光晕 | 9 | 超度目标 |
| 改写节点 | ①-⑫ | 12 | 剧情触发 |

#### 移动系统

```
移动方式:
  步行: 每日 30 里(默认);消耗体力
  骑马: 每日 100 里;需骑术+马匹
  乘船: 顺流每日 200 里;需水路
  官道: 速度 ×1.5;但有关卡(需通行证)
  小路: 速度 ×1.0;可避开关卡;遇匪概率+

路线规划: 选择目的地 → 自动/手动选路 → 显示:
  预计天数 / 沿途事件(已知) / 风险等级 / 怨气浓度
```

## 探索机制

### 发现系统

```
当玩家进入新区域:
  自动触发: 地区名称+简介+当前怨气浓度
  需探索发现(走近): 建筑/NPC/物品/密道
  需技能发现(灵识): 怨魂/圣物/志怪触发点
  需信息战发现: 黑市/内应/密信藏匿点
```

### 快速旅行(Fast Travel)

```
条件: 曾到访过的城市/佛寺
限制: 
  - 围城期间不可快速旅行(城被围)
  - 战争区域需绕行
  - 夜间到达可能遇匪
```

## 天气/时间系统

| 项目 | 影响 |
|---|---|
| 昼/夜 | 夜间: 怨气+10%/视野-/潜行+ |
| 晴/雨 | 雨: 移动-/弓-/潜行+ |
| 季节 | 冬: 口粮消耗+/行军- |
| 特殊(史实) | 台城围城中的"连日大雨"(556 玄武湖淹齐军) → 战斗加成 |
