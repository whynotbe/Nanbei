# 01 系统设计(五大核心系统)

> 数据来源:通史稿全集 + 关系库(223人/233关系/148事件/49志怪/30改写节点)。

## 一、关系网系统(太阁骨架的核心)

### 1.1 数据层
- 关系库已建:223 人物、233 条关系(含 polarity 正负面、confidence 置信度、evidence 原文引文)、每人 20-40 条关系。
- 关系类型 13 种:君臣/姻亲/父子/兄弟/师从/举荐/同僚/交游/仇敌/军事对手/效忠/背叛/收养。
- 游戏端映射:每个人物 NPC 一张"关系卡片",显示一跳关系网(数据库视图 `v_person_network` 已建好,SQL 直查)。

### 1.2 玩法层
| 机制 | 操作 | 史实依据 |
|---|---|---|
| **拉拢** | 送礼/立功/联姻提升 polarity | 侯景免奴为良(阶级动员) |
| **背叛** | polarity 降到底触发倒戈 | 王伟劝侯景:自古岂有叛天子 |
| **荐举** | 上级 NPC 荐你做官,你荐下属 | 陈霸先-萧映-武帝链条 |
| **婚姻** | 联姻锁定盟友(不可轻易解除) | 独孤信一门三皇后 |
| **仇恨** | 杀亲/夺地/辱骂生成永久敌对 | 王僧辩掘陈霸先父墓 |
| **情報** | 别人的关系网可被"打听"(花銭/好感) | 朱异压报侯景异志 |

### 1.3 网络崩塌与重建(核心张力)
- 548 年事件触发后,建康关系网被物理撕碎(士族覆灭,数据库 events 标记 is_rewrite_node 的 30 个节点)。
- 玩家任务:在废网上重建——找活人、确认身份、重组联盟。
- 数据支撑:数据库 `v_person_network` 按年份过滤,展示"活人网"(death_year > 当前年)。

## 二、冤气-超度系统(刀剑血肉的核心)

### 2.1 冤气法则
| 参数 | 值 | 来源 |
|---|---|---|
| 怨气峰值 | 台城/三吴/江陵(三大浩劫点) | 通史稿怨气地图 |
| 扩散半径 | 峰值点向外梯度递减 | 志怪事件地理分布 |
| 影响效果 | ①鬼物显形阈值降低 ②NPC 暴戾度上升 ③超度系效力增强 | 围城抢劫/人相食的"机制解释" |
| 净化方式 | 超度(佛寺锚点)→ 冤气浓度下降 → 解锁改写节点 | 设计决策③ |

### 2.2 显形阈值(明面克制)
- 常态世界:妖魔**不显形**。玩家面对的是人(兵/匪/贪官/叛徒)。
- 显形条件(三选一):冤气浓度 > 80% / 特定时辰(夜/忌日) / 特定仪式(招魂/掘墓)。
- 全局可调参数:`anima_threshold = 80`(改一个数即可调全游戏超自然浓度)。

### 2.3 佛寺锚点(超度系统挂件)
- 三处固定锚点:新平佛寺(苻坚死)/ 三级佛寺(孝庄帝死)/ 净居殿(梁武帝死)。
- 每处锚点:超度任务 + 冤气局部净化 + 获得一件"镇魂"道具。
- 通用小锚点:各州佛寺(数据库 events 中 event_type='志怪' 且 location 非空的条目)。

### 2.4 范缜难题(浓度可玩化)
- NPC 范缜(或其传人)游走全图,与玩家辩论"形存则神存,形谢则神灭"。
- 玩家可选:支持(超自然浓度全局下降→"人间道"结局)/ 反驳(浓度不变)/ 不理。
- **浓度降低的后果**:鬼物绝迹→超度系技能失效→改写节点锁死→只剩"人间线"结局。
- 设计意图:把"要不要超自然"变成玩法选择而非设定争论。

## 三、围城经济系统

### 3.1 核心循环
```
口粮(有限) → 分配(军/民/伤员) → 消耗(天数) → 补给(抢掠/外援/突围)
```
- 围城天数=数据库 events 中该事件的 is_rewrite_node 级别决定。
- 口粮数据:初始值→递减率→外援触发概率→投降/突围/饿死三条出路。

### 3.2 粮价曲线(人相食的侧写)
| 天数 | 粮价 | 事件 |
|---|---|---|
| 1-30 | 正常 | 围城开始 |
| 31-60 | ×10 | 减膳,煮弩烤马鞍 |
| 61-90 | ×100 | 人相食(侧写:NPC 对话提及"那个不再出门的邻居") |
| 91-130 | 无价 | 疫病+死亡率>50%,史实"存者什一二" |

### 3.3 外援系统
- 援军到达时间=关系网深度(你与各路都督的 polarity 总和)。
- **观望机制**:援军到达后不一定攻——polarity < 阈值则"置酒高会"(柳仲礼剧本)。
- 玩家可:冒险出城联络(触发谍报任务)/ 射书求援(纸鸦事件)/ 等待(史实结局)。

## 四、信息战/谣言系统

### 4.1 情报来源
| 渠道 | 操作 | 史实依据 |
|---|---|---|
| 驿传截获 | 派人截杀信使 | 侯景买通台使 |
| 童谣解读 | 听到童谣→查谶谣库→预判事件 | 青丝白马寿阳来 |
| 伪书制作 | 伪造敌方国书/军报 | 侯景伪东魏国书 |
| 俘虏审讯 | 活捉敌将→获取情报(有反诈风险) | 朱序阵前倒戈 |

### 4.2 谣言战(斛律光蓝本)
四段式:投放渠道(市井/军营)→ 内容设计(拆字/谐音)→ 敌方内部放大(谗臣)→ 目标行为(诱杀/出逃)。
游戏实现:制造谣言需"智谋+敌方内部有内应"两个条件;效果=敌方武将忠诚度暴跌→可被离间。

### 4.3 预言自我实现
- 谶谣库:49 条志怪事件中检索,按"预言类"(童谣/梦兆/拆字)分档。
- 玩家听到预言→选择"信/不信/逆向操作"→选择本身影响事件走向。

## 五、宗室名册系统

### 5.1 家族树衰减(皇族生存率表)
- 起始:某朝宗室 N 人(数据库 persons 按 era+faction 筛选)。
- 每次政变/屠戮事件触发 → 对应宗室成员标记死亡(数据库 death_cause 已录)。
- 玩家可视化:族谱图上活人绿色/死人灰色/死因悬停可见。

### 5.2 "天王家"的保险精算
- 每位宗室成员有"威胁值"(承继顺序 × 军权 × 声望)。
- 威胁值高 → 皇帝(或权臣)自动启动清洗 → 玩家可预警/庇护/利用。
- 史实终局:齐宗室"几无遗种"/梁武帝子孙被收割到底——玩家改变任何一个节点,家族树就会分岔。

### 5.3 与关系网联动
- 宗室成员=关系网的"超级节点"(度数高)。
- 杀一个超级节点 → 全网震荡 → 可能触发"复仇标记"(死者的门生故吏对你 polarity 永久 -5)。

---
*系统间的咬合:关系网(人)× 围城(地)× 冤气(天)× 信息(暗线)× 宗室(权力)——五系统互相触发,共同构成"南北朝模拟器"的骨架。*
