# 02 主线剧本(三幕/12改写节点/多结局)

> 起局 547 年正月(设计决策②)。主角=岭南寒门武人(设计决策①)。

## 总结构

```
序章(岭南,547.1-547.8) → 第一幕(建康,547.9-548.10) → 第二幕(围城,548.10-549.3)
→ 第三幕(反攻,551-557) → 尾声(多结局)
```

## 序章:岭南(547.1-547.8)——教程期

**背景**:高欢死讯尚未传到岭南。你是油库吏之子,二十岁,能看见别人看不见的东西。

| 幕 | 剧情 | 教学内容 |
|---|---|---|
| 序1 | 岭南日常:俚人巫鬼文化初次接触,主角的"阴阳眼"设定 | 移动/对话/基础战斗 |
| 序2 | 乡里纠纷→发现一个"冤气"现象(小规模鬼物显形) | 冤气系统/超度入门 |
| 序3 | 陈霸先(同乡前辈)决意北上;你也决定跟去 | 关系网/出行/初始队伍组建 |

**初始关系网**:陈霸先(polarity+2 前辈)/ 父亲(油库吏,polarity+3)/ 俚人巫师(超度导师)/ 1-2 个同乡伙伴。

## 第一幕:北上(547.9-548.10)——观察期

### 节点①:寿阳受降(547)
- **史实**:梁武帝纳侯景,封河南王。
- **玩家**:你在建康朝堂外围,听到萧介的反对(纳之如抱火寝薪)与朱异的逢迎(天道前见其征)。**你可以上书/游说/沉默**——但你是寒门,没人听你的。
- **改写条件**:若玩家在序章积累了足够的"声望"(朝中有人推荐),可以直面上书。效果:置信度+10,但不改变大局。

### 节点②:"贞阳旦至"回信(548)
- **史实**:武帝回信"贞阳旦至,侯景夕返"——信任崩断。
- **玩家**:你截获了这封信(信息战任务)。**选择**:送给侯景(加速叛乱)/ 扣下(延缓)/ 上报(没人信)。
- **改写效果**:扣下→侯景起兵推迟 3 个月(围城缩短)→台城可能不陷。

### 节点③:采石渡江(548.10)
- **史实**:王质遁走,八千人渡江。
- **玩家**:你在采石附近。**选择**:去采石报信(但你是谁,谁信)/ 帮萧正德(投靠叛军线)/ 什么都不做。
- **改写条件**:若玩家声望 > 阈值,可以强行说服王质坚守——八千人渡不了江,侯景困死江北。

## 第二幕:台城围城(548.10-549.3)——核心体验

### 节点④:羊侃之死(548.12)
- **史实**:羊侃病死于围城第五十天,台城支柱塌了。
- **玩家**:你是城中守军之一。**任务链**:找药(城内搜刮/黑市)/ 找医(佛寺僧人有医术)/ 替班(参加土山战)。
- **改写条件**:救活羊侃(需要:药+医+替班三件套全完成)→ 守城天+60 天 → 城可能不陷。

### 节点⑤:援军观望(549.1)
- **史实**:柳仲礼重伤后闭营不战,二十万援军置酒高会。
- **玩家**:你冒险出城,联络各路援军。**任务**:说服柳仲礼(需 polarity > 阈值)/ 直接夺其兵权(高风险高回报)/ 暗杀(改变统帅但可能更糟)。
- **改写效果**:柳仲礼出战 → 侯景被夹击 → 围城解。

### 节点⑥:城破(549.3)
- **史实**:白昙朗董勋华纳贼,城陷。
- **玩家**:城破前夜,你可以:发现内应(需要情报值)/ 护送太子出逃(改变后续)/ 死守到最后一刻(获得"忠魂"标记,冤气峰值强化)。

## 第三幕:反攻(551-557)——收束期

### 节点⑦:巴陵之战(551)
- **史实**:王僧辩坚壁,陆法和赤亭破任约,侯景夜遁。
- **玩家**:你已在荆州系(或陈霸先系,取决于第一幕选择)。**任务**:参与巴陵守城或赤亭伏击。
- **改写条件**:不改变大史实,但你的战斗表现决定战后封赏与关系网深度。

### 节点⑧:江陵焚书(554)
- **史实**:萧绎焚十四万卷,土囊压死,十万口北驱。
- **玩家**:你在江陵(或赶来救援)。**任务链**:说服萧绎不焚书(几乎不可能)/ 偷出一批书(潜行任务)/ 护送颜之推( escort 任务)。
- **改写效果**:偷出书 → 获得"文脉"道具 → 后续结局解锁"文明保全"分支。

### 节点⑨:王僧辩之死(555)
- **史实**:陈霸先夜袭石头城,缢杀王僧辩。
- **玩家**:你知道陈霸先的计划(如果与他关系深)或发现异常(如果与王僧辩关系深)。**终极选择**:告密(救王僧辩,梁不分裂为二)/ 沉默(史实)/ 参与(陈朝功臣线)。
- **改写效果**:救王僧辩→梁朝延续→南朝可能提前统一(但过程更血腥)。

### 节点⑩:反攻线汇总(552)
- 根据前面的改写结果,展示不同的建康光复场景。

### 节点⑪:冼夫人(589)
- **尾声前置**:如果玩家走岭南线,在尾声遇到冼夫人纳土。

### 节点⑫:结局判定

## 多结局设计

| 结局 | 条件 | 描述 |
|---|---|---|
| **史实结局** | 改写节点全不改 | 侯景败死→陈朝代梁→隋灭陈(观察者模式) |
| **人间道** | 冤气净化全部峰值+范缜支持 | 鬼物绝迹→历史正常流转,但玩家平凡终老 |
| **改写结局A:梁中兴** | ④⑤节点改写成功 | 台城不陷→梁朝延续→南北朝延长 |
| **改写结局B:文明保全** | ⑧偷出书+颜之推存活 | 江陵不焚→文化传承→"更好的结局" |
| **改写结局C:寒门王朝** | ⑨参与陈霸先+岭南线全通 | 陈朝提前巩固→南朝统一南方→与北周对峙 |
| **暗结局:入魔** | 冤气全部峰值+玩家使用禁术 | 侯景式结局——你成了新的浩劫 |

## 尾声处理

- 无论哪种结局,最后镜头:建康城(或玩家改写后的城市)的地图,叠加三百年怨气地图(第⑦页)的渐变动画——从鲜红到透明。
- 字幕:"**给南北朝一个更好的结局**——这是你(玩家)的选择。"
