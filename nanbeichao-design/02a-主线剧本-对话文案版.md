## 序章·岭南(547.1-547.8)

### 场景:苍梧·油库(序1)

**[主角在帮父亲清点灯油入库。一个俚人少年被押进来,怀里抱着一个小陶罐。]**

**父亲**:"又是你。偷了三次了,这次说什么也不放。"
**俚人少年**:"不是吃……是给我姐姐点灯。她的魂,还在仓库外面。"
**[阴阳眼触发:仓库门外,一个模糊的灰白色人影在徘徊。]**

**选项A**:"放了他。我帮他姐姐超度。"
→ [解锁超度系统;婆萧好感+2;父亲"你总是心软"声望-1]
→ 进入支线:引魂灯——找到少年的姐姐遗骨,安葬,第一个超度仪式。

**选项B**:"按规矩来。偷了就是偷了。"
→ [体制线;父亲好感+1;少年被杖二十。夜晚,仓库外的灰白人影更加清晰——她在看着你。]

**选项C**:"放了他,别管什么鬼。"
→ [中立;少年跑了;后续仓库会闹鬼(小事件),需要回来补做超度。]

## 节点①:寿阳受降(547)

### 场景:建康·朝堂外(你站在宫墙外,听传旨官宣布)

**传旨官**:"诏曰:封侯景为河南王、大将军、使持节,都督河南南北诸军事——承制如邓禹故事!"

**[路过的老臣(谢举,如果你声望够高可以认出他):**
**谢举**:"纳之如抱火寝薪啊……"
**主角**:"大人,您是说……"
**谢举**:"年轻人,你不懂。我等议了三天,说'纳景非宜',陛下不听。梦里都梦见中原牧守来降了——那是个梦啊。"

**选项A**:上书反对(需要声望 ≥ 阈值)
→ [上书被朱异压下;声望+5;朱异 polarity-2;无实际效果——史实不变]
**选项B**:沉默观察
→ [记录事件到"谶谣库":"武帝中原之梦";无效果]
**选项C**:去找朱异(需要关系网中有朱异的门生)
→ [朱异:"侯景数百叛虏,何能为役"——触发后续节点②的伏笔]

## 节点②:"贞阳旦至"回信(548)

### 场景:建康·驿馆外(你截获了一封信)

**[信息战任务成功。你手中是武帝的回信:"贞阳旦至,侯景夕返。"]**

**旁白**:"这封回信,侯景的人已经截到了。但你也截到了——如果你够快。"

**选项A**:抢先送到侯景手中
→ [加速叛乱;侯景阵营好感+3;后续围城事件+30 天难度]
**选项B**:扣下信件,销毁
→ [延缓叛乱 3 个月;台城围城缩短;需要"潜行"技能 ≥ 3]
**选项C**:上报朝廷
→ [朝廷不以为意("景必无渡江之理");无效果;声望+2]

## 节点③:采石渡江(548.10)

### 场景:采石·江边(夜。你看到远处有火光——是侯景的军队在渡江)

**[王质已经撤走。你站在采石渡口,身后是一片空荡荡的营地。]**

**旁白**:"八千人。马数百匹。正在渡江。你一个人。"

**选项A**:冲回去报信
→ [你跑到建康,城门已闭;守军不信你是谁;效果:声望+3,无实际改变]
**选项B**:放火点燃渡口烽燧
→ [需要"军务"技能 ≥ 2;效果:侯景渡江延迟一夜;台城准备时间+1 天]
**选项C**:什么都不做
→ [史实:京师不之觉。]

## 节点④:羊侃之死(548.12)

### 场景:台城·羊侃病房

**[台城被围第五十天。守城总指挥羊侃病倒了。城中缺药。你站在他的病榻前。]**

**羊侃**(虚弱地):"你是……新来的?"
**主角**:"是。从岭南来的。"
**羊侃**:"岭南……好远。你为什么要来这里?"
**主角**:"[选项]"
- "我跟陈将军来的。"
- "我听说这里需要人。"
- "我也想知道,我能做什么。"

**羊侃**:"好。记住——**我倾宗报主,犹恨不足,岂复计此一子。**"(他指的是他的长子被侯景抓来城下,他引弓射之的事。)

**任务链**(三件套,全部完成才能救活羊侃):
1. **找药**:城内搜刮(潜行)/黑市交易(金帛)/佛寺求药(僧人有医术)。
2. **找医**:找会医术的僧人(需要佛寺好感 ≥ 阈值)。
3. **替班**:参加一次土山战(战斗任务,消耗 HP)。

**[三件套完成]→ 羊侃活:守城+60 天 → 台城可能不陷**
**[未完成]→ 羊侃死:史实线**

## 节点⑤:援军观望(549.1)

### 场景:台城外·柳仲礼大营

**[你冒死出城,穿过侯景的封锁线,来到城外二十万"援军"的营地。柳仲礼重伤初愈,正在饮酒。]**

**柳仲礼**(看到你):"城里的?你怎么出来的?"
**主角**:"游过秦淮河。"
**柳仲礼**:"好胆色。来,喝一杯。"

**[你注意到:营中没有战备的迹象。乐声、酒香、笑谈。]**

**选项A**:直面质问
→ "柳将军!城中每天都在死人!您拥兵二十万,为什么不战?"
→ 柳仲礼:"小儿,你懂什么。"(好感-2,但触发后续选项)
→ 追加选项:"我懂——我懂你爹还在城里!"(需要知道柳津是柳仲礼之父)
→ [柳仲礼沉默,握杯的手在颤抖。好感+3,出战概率+20%]

**选项B**:游说副将
→ [需要"口才" ≥ 3;绕过柳仲礼,说服裴之高等;效果:部分援军出动,但不协统]

**选项C**:暗杀柳仲礼(暗线)
→ [需要"暗杀"技能;效果:援军换帅,可能更好也可能更糟——随机]

→ [战斗任务;获得"忠魂"标记;后续冤气系统强化;城依然破]

## 节点⑨:王僧辩之死(555)

### 场景:建康·石头城外(夜)

**[陈霸先的军队正在渡江。你知道他的目标——王僧辩。你同时认识两个人。]**

**陈霸先**(如果你与他关系深):"**委公北门,何谓无备。**——这是他说的。你知道他是什么意思吗?他把北门的安全全权托付给我。而我,要杀他。"
**主角**:"为什么?"
**陈霸先**:"因为他迎立了齐人的傀儡。梁朝不能姓萧又姓高。"

**终极选择**:
**选项A**:告密(救王僧辩)
→ [王僧辩提前防备;陈霸先失败;梁朝分裂为二;后续更血腥]
**选项B**:沉默
→ [史实:王僧辩被缢杀;南朝最后一个"好人对杀"落幕]
**选项C**:参与(陈朝功臣线)
→ [陈霸先好感 MAX;后续陈朝你成为开国功臣;但你手上有盟友的血]
