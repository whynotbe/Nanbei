### 成长规则

```
每项属性需"使用次数"达到阈值后自动+1:
  武力: 参与战斗(每场 1 次,累计)
  智谋: 解谜/情报分析/谏言
  体质: 生存事件/ endure / 好好吃饭
  敏捷: 跑酷/闪避/暗器
  魅力: 社交/声望事件
  灵识: 超度/志怪事件/冥想

阈值递增: 3→4 需 15 次,4→5 需 25 次,5→6 需 35 次...
公式: 阈值 = (当前值 - 2) × 10 + 5

名师加成: 该属性成长速度 ×2(消耗资源)
年龄衰减: 557 年后体质/敏捷每年 -1
```

## 伤害公式汇总

### 物理伤害

```
基础伤害 = 武器攻击力 × (1 + 武力 × 0.05)
最终伤害 = 基础伤害 × 部位系数 × 暴击系数 - 目标防御

部位系数: 头 ×2.0 / 躯干 ×1.0 / 四肢 ×0.7
暴击率 = 敏捷 × 2%(上限 40%)
暴伤 = ×1.5(固定)
防御 = 目标装备防御 + 目标体质 × 0.3
```

### 超度伤害(对鬼物)

```
超度伤害 = 技能基础 × (1 + 灵识 × 0.08) × 怨气浓度加成
怨气浓度加成 = 1 + (当前区域怨气浓度 / 100) × 0.5
圣物加成 = ×1.5(佛牙/舍利)
禁术加成 = ×2.0(但暴戾度+10)
```

### 骑乘冲锋

```
冲锋伤害 = 武器攻击力 × (1 + 武力 × 0.05) × 1.3 × 冲锋距离系数
冲锋距离系数: 短(10m)=1.0 / 中(30m)=1.3 / 长(50m)=1.5
```

## 死亡/失败

| 情况 | 后果 |
|---|---|
| 战斗 HP=0 | 倒地 → 读档(自动存档点) |
| 围城城破 | 不是"死亡" → 切入后续剧情(城破后的故事) |

| 入魔(暴戾度91+) | 不可逆;游戏继续但进入暗结局线 |
