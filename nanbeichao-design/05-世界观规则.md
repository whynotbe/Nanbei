# 05 世界观规则书(怨气法则/显形/佛寺/范缜)

## 总纲

南北朝世界有"两层":**人间层**(正史记载的一切——战争/政变/饥荒/朝代更替)和**冤气层**(大量非正常死亡者怨气凝聚成的场,影响人间层的物理与心理)。

**核心原则:冤气不是超自然,是这个世界的"暗物质"。** 正史里所有的"异常"(童谣应验/鬼梦/天象/预言),在本世界观里都被解释为冤气浓度变化的外在表现。

---

## 一、怨气法则

### 1.1 产生
- 每一个"非正常死亡"(战死/被杀/饿死/冤死)产生怨气单位。
- 怨气不消散,在地理上积累——**浩劫之地=怨气峰值**。
- 数据来源:关系库 events 表,event_type IN ('战争','灾异','政变') 且有人口死亡数据的条目。

### 1.2 分布(怨气地图)
| 峰值 | 浓度 | 事件 | 年代 |
|---|---|---|---|
| 宁平城 | 高 | 十余万人覆没 | 311 |
| 参合陂 | 高 | 四五万降卒坑杀 | 395 |
| 统万城 | 中 | 人墙(筑尸入墙) | 413 |
| 河阴 | 高 | 两千朝官沉河 | 528 |
| 玉壁 | 中 | 七万人战死 | 546 |
| **台城** | **极高** | **十余万军民存者什一二** | **549** |
| **三吴** | **极高** | **千里绝烟白骨成聚** | **551** |
| **江陵** | **极高** | **焚书十万口北驱** | **554** |
| (全图其余) | 低-中 | 各地零星战乱 | — |

### 1.3 影响(三层)
1. **物理层**:鬼物显形阈值降低(见第二节)。
2. **心理层**:NPC 暴戾度上升(围城抢劫/人相食等史实惨剧的"机制解释")——在怨气浓区,原本善良的 NPC 也会做出残忍选择。
3. **系统层**:超度系技能效力增强(有鬼可超,才有超度的用武之地)。

### 1.4 净化
- **方式**:在峰值点进行超度仪式(需:佛寺锚点 or 巫术仪式)。
- **效果**:浓度下降 → 解锁一个改写节点(设计决策③"净化↔改写绑定")。
- **全局效果**:若全部峰值净化 → 鬼物绝迹 → 达成"人间道"结局。

## 二、显形阈值(明面克制)

### 2.1 常态世界
**妖魔不显形。** 玩家 95% 的时间面对的是人:士兵/土匪/贪官/叛徒/饥民。这保证历史叙事的严肃感。

### 2.2 显形条件(三选一)
| 条件 | 参数 | 效果 |
|---|---|---|
| 怨气浓度 | > 80%(峰值点核心区) | 鬼物自动显形 |
| 时辰 | 夜间/忌日/暴雨 | 浓度 > 50% 区域鬼物可显形 |
| 仪式 | 招魂/掘墓/血祭 | 主动召唤,不依赖浓度 |

### 2.3 全局可调参数
```python
anima_threshold = 80  # 显形阈值(0-100)
# 改一个数字即可调全游戏超自然浓度
# 100 = 纯历史(无鬼物)
# 0   = 全图鬼物横行(纯粹的刀剑封魔录)
```

### 2.4 鬼物设计
| 类型 | 来源 | 强度 |
|---|---|---|
| **怨魂**(最低级) | 单一非正常死亡者 | 杂兵 |
| **厉鬼** | 高浓度怨气凝聚(多魂合一) | 精英怪 |
| **怨灵将** | 战场万人坑(玉壁/宁平城级) | BOSS |
| **魔**(唯一) | 侯景——民间记忆将他"铸魔" | 终极 BOSS |

## 三、佛寺锚点

### 3.1 三大固定锚点(超度系统的"基地")
| 锚点 | 地点 | 关联人物 | 超度奖励 |
|---|---|---|---|
| 新平佛寺 | 关中 | 苻坚(385 死于此) | 镇魂塔模型 |
| 三级佛寺 | 晋阳 | 孝庄帝(530 缢死于此) | "天威"buff |
| 净居殿 | 建康台城 | 梁武帝(549 饿死于此) | "荷荷"音效彩蛋 |

### 3.2 通用锚点
- 各州佛寺(南朝佛寺 500+):提供小规模超度+存档。
- 数据来源:关系库 events 表中 event_type='志怪' 且 location 含"寺"的条目。

### 3.3 超度仪式(简化设计)
```
找到遗骨/遗物 → 携至佛寺 → 选择经文(影响净化效果) → 完成
```
- 巫术路线:婆萧教的俚人巫术(不需佛寺,但效力较弱)。
- 佛道路线:找僧人(需 polarity 达标,或付钱)。
- **禁术路线**(暗结局线):吸收怨气化为己用——效力最强,但你的暴戾度上升。

## 四、范缜难题(超自然浓度的哲学阀门)

### 4.1 背景
范缜(约 450–510)提出"神灭论"——"形存则神存,形谢则神灭"。两次孤身对抗国家级围攻(萧子良沙龙/梁武帝朝堂),赢了逻辑,输了仕途。

### 4.2 游戏实现
- 范缜本人死于游戏时间线之前,但**"神灭论"由匿名弟子传承**。
- 玩家在全地图随机遇到"神灭论者"NPC(可能是路边老者/书院学者/被贬官员)。
- 每次 encounter:一场小型辩论(选择"支持/反驳/沉默")。
- **支持次数 > 阈值** → 全局 `anima_threshold` 上升(鬼物更少)。
- **反驳次数 > 阈值** → 全局 `anima_threshold` 下降(鬼物更多)。

### 4.3 人间道结局
- **条件**:净化全部 9 个怨气峰值 + 支持范缜次数 ≥ 5。
- **效果**:鬼物彻底绝迹 → 超度系统失效 → 改写节点锁死。
- **结局画面**:纯人间线——玩家作为寒门武人,在陈朝(或改写后的梁朝)做一个平凡官员,老死户牖。字幕:"**没有鬼的世界,历史依然残酷——但那是人的残酷,不是天的。**"

### 4.4 设计意图
把"超自然浓度"从设定争论变成**玩家的道德选择**:
- 你要一个有鬼的世界(战斗系统更爽,但惨剧更重)?
- 还是一个无鬼的世界(悲剧只是人的,但你也失去了改变命运的武器)?

## 五、天命与预言系统

### 5.1 谶谣库
数据来源:关系库 events 表中 event_type='志怪' 的 49 条,按类型分:
- **童谣**("青丝白马寿阳来"/"的脰乌,拂朱雀,还与吴")
- **梦兆**(武帝中原之梦/简文梦吞土/阴智伯异光之梦)
- **拆字**("百日天子"拆"侯景"字)
- **天象**(白虹贯日/荧惑在天尊)
- **祥瑞**(甘露/玉玺/佛牙/白龙)

### 5.2 玩法
- 玩家听到童谣 → 打开"谶谣库"查询 → 获得关于未来事件的模糊提示。
- **自我实现**:玩家的"相信"本身会加速事件发生(如:你相信"青丝白马",所以你在寿阳看到白马时更容易不设防)。
- **逆向操作**:玩家若不信,可以选择"反着来"(如:明知道采石会失守,偏去采石守)。

### 5.3 天命的真相
- **世界观内解释**:所有预言都是"冤气共振"——大量怨气聚集时,敏感的人(主角/僧通/宝志)能感知到"即将发生的浩劫"。
- **世界观外解释**:历史有其惯性,但每个节点都可改写——这是"给南北朝一个更好的结局"的机制基础。

### 6.3 改写规则
- **单点改写**:改变一个节点 → 后续事件链偏移(但不完全崩坏)。
- **多点改写**:改变 3+ 节点 → 进入"新史实线"(可能更好,也可能更糟)。
- **改写代价**:每次改写消耗"气运"(资源);气运不足时强行改写 → 冤气反噬 → 你的暴戾度上升。
