# 09 事件改写系统(策划案)

## 概述

39 个改写节点(数据库 `is_rewrite_node=1`),12 个为主线节点。每个节点是"史实的断点"——玩家的选择决定历史走向哪条路。**改写不是"蝴蝶效应"的模糊叙事,是明确的多分支因果链。**

## 数据结构(已建)

```sql
-- events 表中 is_rewrite_node=1 的 39 条
id, year_ce, month, title, summary, event_type, location,
evidence(原文), source_id
```

## 改写机制

### 触发条件

```
改写节点触发 = 
  时间到达(年份+月份匹配)
  AND 地点到达(玩家在该区域)
  AND 前置条件(部分节点需特定属性/关系网深度)
  AND 冤气条件(部分节点需先净化对应峰值)
```

### 选择界面

```
┌─────────────────────────────────────┐
│  ⚡ 改写节点:⑤援军观望                │
│                                     │
│  史实: 柳仲礼重伤后闭营不战,          │
│  二十万援军置酒高会,台城陷落。        │
│                                     │
│  你冒死出城,来到柳仲礼大营。          │
│                                     │
│  [A] 直面质问:"城中每天都在死人!"    │
│  [B] 游说副将(需口才≥3)             │
│  [C] 暗杀柳仲礼(需暗器≥3)           │
│  [D] 什么都不做(史实)               │
│                                     │
│  ⚠ 此选择将影响后续 3 个事件          │
└─────────────────────────────────────┘
```

### 后果链(Consequence Chain)

每个改写选项产生"世界状态变更",影响后续事件:

```
节点⑤ 改写成功(柳仲礼出战)
    ↓
  侯景被夹击 → 围城解(节点⑥不触发)
    ↓
  台城不陷 → 武帝不死 → 简文帝不立
    ↓
  节点⑦(巴陵)不触发 → 萧绎不称帝
    ↓
  节点⑧(江陵焚书)不触发 → 后梁不立
    ↓
  节点⑨(王僧辩之死)条件变化
    ↓
  结局: "梁中兴" / "文明保全" 方向
```

### 改写代价

| 改写 | 消耗 |
|---|---|
| 每次成功改写 | "气运"资源 -10 |
| 气运不足强行改写 | 暴戾度+10(冤气反噬) |
| 气运获取 | 超度(每净化 1 个峰值+20)/善行/任务奖励 |

## 多结局设计(详细条件)

| 结局 | 条件组合 | 描述 | 画面 |
|---|---|---|---|
| **史实结局** | 改写节点全不改 | 侯景败死→陈朝→隋灭陈 | 观察者模式;片尾字幕滚 |
| **人间道** | 净化全部峰值+范缜≥5 | 鬼物绝迹;历史正常流转 | 纯人间;平凡终老 |
| **梁中兴** | ④⑤改写成功 | 台城不陷;梁朝延续 | 武帝老死;南北对峙延长 |
| **文明保全** | ⑧偷出书+颜之推存活 | 江陵不焚;文化传承 | "更好的结局" |
| **寒门王朝** | ⑨参与陈霸先+岭南全通 | 陈朝巩固;南朝统一南方 | 与北周对峙 |
| **入魔** | 冤气全峰+禁术使用 | 你成了新的浩劫 | 侯景式结局;漆首武库 |

## 数据库查询(引擎端)

```sql
-- 获取所有改写节点
SELECT * FROM events WHERE is_rewrite_node=1 ORDER BY year_ce, month;

-- 获取某年的活跃事件
SELECT * FROM events WHERE year_ce = 548 AND event_type != '志怪';

-- 获取某地点的怨气峰值
SELECT * FROM events WHERE event_type IN ('战争','灾异') AND location LIKE '%台城%';
```

## 与其他系统的接口

| 系统 | 接口 |
|---|---|
| 所有系统 | 核心输出:改写节点触发后,全系统状态变更 |
| 冤气超度 | 净化=解锁改写选项 |
| 关系网 | 部分改写需关系网深度 |
| 围城经济 | 节点④⑤⑥在围城段 |
| 宗室名册 | 改写可能改变宗室死亡 |
