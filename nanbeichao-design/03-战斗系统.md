# 03 战斗系统(策划案)

## 概述

双模式战斗:**人战**(对人类敌人,写实动作)和**鬼战**(对怨气凝聚体,超度/净化系)。常态世界 95% 是人战;怨气浓区/夜间/仪式触发鬼战。两种模式共享基础操作,但技能树/伤害类型/击杀逻辑不同。

## 人战(Human Combat)

### 基础操作(ARPG 骨架)

| 操作 | 按键(默认) | 说明 |
|---|---|---|
| 移动 | WASD | 全向移动 |
| 闪避 | Space | 消耗精力,无敌帧 0.3s |
| 轻攻击 | LMB | 速度快/伤害低 |
| 重攻击 | RMB(长按) | 破防/伤害高/消耗精力 |
| 格挡 | MMB(或 Q) | 减伤 60%,完美格挡(0.1s 窗口)弹反 |
| 使用道具 | 1-4 | 快捷栏 |
| 锁定 | Tab | 锁定/切换目标 |
| 特殊技能 | E | 当前装备的战斗技能 |
| 超度(鬼战) | F | 净化(仅鬼战) |

### 武器类型

| 武器 | 攻速 | 伤害 | 特殊 | 克制 |
|---|---|---|---|---|
| 直剑 | ★★★ | ★★ | 均衡,连击流畅 | vs 无甲 |
| 大刀 | ★★ | ★★★ | 破甲/范围 | vs 重甲 |
| 长枪 | ★★ | ★★★ | 距离/骑乘/破阵 | vs 骑兵 |
| 弓 | 远程 | ★★ | 需敏捷/箭矢 | vs 远程 |
| 短刃 | ★★★★ | ★ | 潜行/暗杀 | vs 无防备 |
| 铁棒(袖棒) | ★★ | ★★ | 混钝/震慑 | vs 甲(尔朱荣蓝本) |

### 伤害公式

```
物理伤害 = 武器基础 × (1 + 武力 × 0.05) × 部位系数 × 暴击系数 - 目标防御
部位系数: 头 ×2.0 / 躯干 ×1.0 / 四肢 ×0.7
暴击: 敏捷 × 2% 概率,暴伤 ×1.5
破防: 重攻击命中格挡状态 → 目标"破防"(2s 不能格挡)
```

### 骑乘战斗

| 项目 | 规则 |
|---|---|
| 上/下马 | E 键交互(需骑术 ≥ 1) |
| 马匹 HP | 独立血条,可被击杀(马死需重新获取) |
| 骑乘攻击 | 攻击力 ×1.3(冲锋动能) |
| 骑枪冲锋 | 骑术 ≥ 3+长枪: 直线冲锋,首个命中 ×2 伤害 |
| 被击落 | 受重击/马死 → 落马(倒地 1.5s) |

### 以步制骑(史实系统)

| 战术 | 条件 | 效果 |
|---|---|---|
| 却月阵 | 智谋 ≥ 5+盾防+特定地形(水边) | 骑兵冲锋伤害反弹 50% |
| 拒马枪 | 长枪+蹲防 | 骑兵冲锋自杀式伤害 |
| 袖棒 | 铁棒+敏捷 ≥ 5 | 骑兵近身反击(尔朱荣"刀不如棒") |
| 地形利用 | 在窄巷/山地/建筑内 | 骑兵无法冲锋 |

### 军团战(战场模式)

当参与大规模战役(改写节点触发)时,切入场面视角:

| 项目 | 规则 |
|---|---|
| 规模 | 最多 100v100(LOD 远景) |
| 玩家定位 | 前线战士(可斩将)/中军指挥(智谋 ≥ 8)/传令兵(特殊任务) |
| 斩将 | 击杀敌方将领 → 敌方全军士气 -30%(可能溃散) |
| 士气 | 0-100,低于 30 时 AI 可能溃逃 |
| 阵型 | 玩家可建议阵型(需战术 ≥ 3):却月/长蛇/方阵/雁行 |

## 鬼战(Supernatural Combat)

### 触发条件

```
IF 怨气浓度 > 80 AND (夜间 OR 仪式 OR 忌日)
    → 鬼物显形
IF 怨气浓度 > 50 AND 夜间
    → 低级怨魂可能出现
IF 玩家主动招魂/掘墓
    → 强制触发
```

### 鬼物分类

| 类型 | 来源 | 强度 | 弱点 |
|---|---|---|---|
| 怨魂(灰白) | 单一非正常死亡 | ★ | 基础超度可净化 |
| 厉鬼(暗红) | 高浓度怨气聚合 | ★★★ | 需巫术或佛寺超度 |
| 怨灵将(金甲) | 万人坑(玉壁/宁平城) | ★★★★★ | 需圣物+高级超度 |
| 魔(唯一) | 侯景(死后) | ★★★★★★ | 终极 BOSS,需全部准备 |

### 伤害机制

- **物理攻击对鬼**: 伤害 ×0.1(几乎无效,但可打断其动作)
- **超度攻击**: 造成"净化伤害"(灵识 × 0.5 × 技能倍率)
- **圣物加持**: 佛牙/舍利 → 物理攻击对鬼 ×0.5(可物理砍鬼)
- **禁术**: 吸收怨气 → 你的物理攻击对鬼 ×1.0(但暴戾度+10/次)

### 超度流程(非战斗型)

```
发现怨气源(遗骨/遗物/凶宅)
    → 感知(灵识检定)确认类型
    → 选择方式:
       A. 巫术超度(不需佛寺,效力弱,消耗灵识)
       B. 佛寺超度(需僧人好感,效力强)
       C. 安葬(需体力劳动,慢但无消耗)
       D. 禁术吸收(快,但暴戾度+)
    → 完成后: 怨气浓度下降,可能获得"善缘"buff
```

### 暴戾度(禁术的代价)

| 暴戾度 | 效果 |
|---|---|
| 0-30 | 正常 |
| 31-60 | NPC 对话选项减少(人们怕你);夜间噩梦(HP 回复减半) |
| 61-90 | 部分正派 NPC 拒绝交互;鬼物主动攻击你 |
| 91+ | 进入"入魔"线(不可逆);结局锁死为暗结局 |
| 降低方式 | 超度(不做吸收)/佛寺忏悔/行善/时间流逝(每天-1) |

## 战斗 AI 规则

| 敌人类型 | AI 行为 |
|---|---|
| 士兵(杂兵) | 群体包围/轮流攻击/士气溃逃 |
| 精英武将 | 会格挡/闪避/使用技能/可能呼叫支援 |
| 弓手 | 保持距离/优先射低 HP 目标 |
| 骑兵 | 冲锋→绕行→再次冲锋(怕拒马/窄地) |
| 怨魂 | 漂浮接近/物理免疫/被超度击退 |
| 厉鬼 | 会附身 NPC(控制其攻击你)/范围怨气伤害 |
| 怨灵将 | 会召唤怨魂/需先清理小怪再攻击本体 |

## 与其他系统的接口

| 系统 | 接口 |
|---|---|
| 角色养成 | 武力/敏捷/体质直接决定战斗数值 |
| 冤气超度 | 鬼战的核心解决方式 |
| 关系网 | 援军到达/援军观望/背刺 |
| 围城经济 | 守城战=战斗+资源管理混合 |
| 事件改写 | 战斗表现影响改写节点评价 |
