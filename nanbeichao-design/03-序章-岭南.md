# 03 序章·岭南(教程三幕)

> 起局 547 年正月,高欢死讯尚未传到岭南。

## 主角设定

- **姓名**:可自定义(默认:陈文清——虚构名,"文清"取"文清浙浙"的岭南水意象)
- **出身**:吴兴长城人(与陈霸先同乡),父为油库吏,家在岭南苍梧/高要一带
- **年龄**:20 岁(527 年生)
- **能力**:武艺(乡里水平)+ **阴阳眼**(能看见常人看不见的"冤气"——这是他天生异禀,不是修行得来)
- **性格**:正义但不迂腐,重情但知道取舍(玩家可选倾向)

## 初始关系网(3 个 NPC + 2 个可选)

| NPC | 身份 | polarity | 功能 |
|---|---|---|---|
| 父亲(陈老爹) | 油库吏 | +3(至亲) | 序章引导人,提供"体制内底层"视角 |
| 陈霸先 | 同乡前辈(西江督护) | +2(敬仰) | 序3 关键:他的决定触发你的北上 |
| 俚人巫师( fictitious 名"婆萧") | 本地巫鬼文化的守护者 | +1(导师) | 冤气系统教学:教你看/净化/超度 |
| 同伴A(可选) | 汉人猎户/渔民 | +2(发小) | 战斗搭档/背包 |
| 同伴B(可选) | 俚人少女(巫师弟子) | +1(暧昧线可选) | 超度搭档/感情线 |

## 序1:苍梧日常(547.1-547.3)

**场景**:岭南苍梧郡,油库(贮存灯油的仓库)。你在帮父亲清点入库,一个俚人少年偷油被抓。

**事件**:俚人少年偷油不是为吃——是为给死去的姐姐点灯("引魂灯")。你用阴阳眼看到:他姐姐的鬼魂在仓库外徘徊,不肯走。

**选择**:
- A. 放了他+帮他姐姐超度(走巫鬼线,学会第一个超度技能)
- B. 按规矩上报(走体制线,父亲加分但少年被罚)
- C. 私下放了他但不管鬼(中立,后面鬼会来找你)

**教学**:对话/移动/基础交互/第一个道德选择(无对错,但影响后续 NPC 态度)。

## 序2:冤气初现(547.4-547.6)

**场景**:附近一个废弃村庄(三年前俚人与官军冲突的遗址)。

**事件**:婆萧(巫师)带你去看"怨气之地"——你用阴阳眼看到:整片土地上空弥漫着灰红色的雾,雾中有模糊的人形在走动。婆萧解释:这不是鬼,是"冤气"——大量非正常死亡的人的怨气凝聚成的场。

**机制教学**:
- 冤气浓度(你看这片区域是深红色)
- 浓度影响:NPC 在此地对话会变得更暴躁(暴戾度+20%)
- 超度方法:找到遗骨→安葬→诵经(或巫术,取决于你跟谁学)
- **关键发现**:你天生对冤气敏感——别人看不到,你能看到。这不是病,是"眼"。

**伏笔**:婆萧说:"你的眼,是你祖上修来的,也是你欠下的。"——为后续范缜难题做铺垫。

## 序3:陈霸先北上(547.7-547.8)

**场景**:高要郡,陈霸先的营地。你因序2表现出色,被乡里推荐给他(或你自己来投,取决于声望)。

**事件**:陈霸先正在决策——广州刺史萧勃不让他北上(钟休悦的"未若且住始兴"说辞),但他收到了北方大乱的消息。你来的时候,他正在看一份密报(侯景叛东魏,河南十三州降梁)。

**对话**:陈霸先看着你:"北边乱了。你是跟我走,还是留在岭南?"

**选择**:
- A. 跟你走(进入主线,离开岭南)
- B. 我再想想(可继续做支线,但序章不会结束直到你选择走)

**选择走的那一刻**——序章结束,画面:你背上简陋的行囊,回头看了一眼父亲和婆萧。父亲说:"去吧,但记住,你姓陈,不姓别的。"婆萧递给你一个小布包(里面是一块 dried 硃砂,超度用的)。

**Fade out → 第一幕开始。**

## 教学覆盖清单

| 系统 | 教学场景 |
|---|---|
| 移动/对话 | 序1 全程 |
| 道德选择 | 序1 偷油事件 |
| 战斗(基础) | 序2 废村(小型鬼物=训练用) |
| 冤气感知 | 序2 婆萧教学 |
| 超度/净化 | 序2 第一个超度 |
| 关系网(查看/交互) | 序3 营地(第一个正式关系卡片) |
| 声望/身份 | 序3 被推荐(或自荐) |
| 出行/地图 | 序3 结束(北上) |

## 音画基调

- **岭南**:湿热、苍翠、蝉鸣,巫鬼文化的图腾(铜鼓/独木舟/槟榔)——与后面建康的"雅致江南"形成视觉对比。
- **音乐**:岭南用俚人风格的竹管+铜鼓;北上后渐变为汉式丝竹;围城期转为低沉钟磬。
- **色彩**:岭南=饱和绿+暖金(阳光),冤气区=去饱和+灰红叠加。

---
*序章设计原则:不教"怎么打",教"这是什么世界"——岭南的湿热、巫鬼、寒门,是玩家理解整个南北朝的锚点。*
