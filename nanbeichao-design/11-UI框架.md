# 11 UI 框架(策划案)

## 概述

南北朝的 UI 应该"看不见"——沉浸感优先。信息通过环境叙事(NPC 对话/场景视觉/物品描述)传达,菜单和 HUD 尽量极简。

## HUD(抬头显示)

### 战斗中

```
左上: HP 条(红色) / 精力条(绿色)
右上: 小地图(圆/方) / 当前目标
左下: 快捷栏 ×4(道具)
右下: 技能 CD(战斗技能/超度)
中央: 锁定标记 / 伤害数字(可关闭)
底部: 交互提示("E: 拾取"/"F: 超度")
```

### 非战斗

```
左上: 日期(548年10月) / 天气 / 怨气浓度(阴阳眼)
右上: 小地图 / 当前任务
底部: 无(HUD 隐藏,按需呼出)
```

## 主菜单结构

```
[开始游戏] → [新游戏] / [继续] / [章节选择(解锁后)]
[关系网] → 力导向图可视化
[谶谣库] → 预言列表+解读
[物品] → 背包(简化)
[技能] → 属性+技能树
[地图] → 三层地图
[系统] → 设置/存档/退出
```

## 对话系统

### 基础对话(90% 场景)

```
底部对话框:
┌─────────────────────────────────────┐
│  [NPC 头像]  NPC 名称 · 身份           │
│                                     │
│  对话内容(逐字显示,可跳过)             │
│                                     │
│  > 选项 A                            │
│  > 选项 B                            │
│  > 选项 C(需条件)                    │
│  > [结束对话]                         │
└─────────────────────────────────────┘
```

### 特殊对话(改写节点)

```
全屏对话框(暂停游戏):

│  ⚡ 改写节点: ⑤援军观望                │
│                                     │
│  [场景描述/旁白]                       │

│                                     │
│  ⚠ 此选择将影响后续 3 个事件            │
└─────────────────────────────────────┘
```

## 关系网可视化(D3.js 力导向图)

### 布局

```
中心 = 玩家(金色节点)
一跳 = 直接关系 NPC(颜色 = polarity)
二跳 = 拉拢后解锁(半透明)
线 = 关系类型(粗细 = weight,颜色 = polarity)
```

### 交互

```
悬停 → 显示 NPC 简要信息
点击 → 弹出 NPC 卡片(详细属性/操作)
拖拽 → 调整布局(自动回弹)
缩放/平移 → 浏览大网
筛选 → 按阵营/关系类型/polarity 范围过滤
```

## 怨气感知覆盖层

```
浓度 0-20%: 无视觉变化
浓度 21-50%: 边缘灰色 vignette
浓度 51-80%: 红色 vignette + 微弱人影
浓度 81-100%: 深红 vignette + 空气扭曲 + 怨魂可见 + 耳语声

UI 元素:
  右上角: 怨气浓度百分比 + 颜色条
  检测到怨魂: 屏幕边缘红色脉冲
  佛寺范围内: 金色光晕(安全区标记)
```

## 存档系统

| 项目 | 规则 |
|---|---|
| 存档点 | 佛寺(主存档)+ 手动(任意安全区) |
| 围城中 | 每日自动存档(不可手动覆盖) |
| 改写节点 | 选择前自动快照(可回看但不能回退) |
| 存档内容 | 世界状态+角色+关系网+物品+改写历史 |
