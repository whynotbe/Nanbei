# 南北朝人物关系库(游戏用)

从公版正史独立构建的人物/关系/事件数据库。

## 合规底线(已写进代码注释,勿删)
1. 输入只允许公版史料文本(维基文库对照本优先);禁止读入任何 CBDB 文件;
2. 每条关系必带 evidence 原文引文,否则不入库;
3. 每次抽取写 extractions 留证;
4. schema 按游戏玩法定义,不复刻 CBDB 分类编码。
